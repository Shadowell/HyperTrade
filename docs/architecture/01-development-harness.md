# 01 Development Harness / 开发 Harness

## English

The repository adopts `codex-project-template` as the delivery operating system. Every non-trivial change should be traceable through spec, sprint contract, progress, verification, and QA notes.

Key files:

- `AGENTS.md`: stable working rules for Codex.
- `docs/spec.md`: product and system intent.
- `docs/contracts/`: sprint-sized implementation contracts.
- `docs/progress.md`: current state and handoff.
- `scripts/check.sh`: one verification entrypoint.

## 中文

仓库使用 `codex-project-template` 作为交付操作系统。所有非平凡改动都应该能从 spec、sprint contract、progress、verification 和 QA 记录里追踪。

关键文件：

- `AGENTS.md`：Codex 稳定工作规则。
- `docs/spec.md`：产品和系统意图。
- `docs/contracts/`：按 Sprint 拆分的合同。
- `docs/progress.md`：当前状态与交接。
- `scripts/check.sh`：统一验证入口。
