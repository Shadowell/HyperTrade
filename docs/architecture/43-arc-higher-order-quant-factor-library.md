# 43. ARC Higher-Order Quant Factor & Operator Library Architecture

## 1. Executive Summary

This specification defines **Phase 2 of the ARC Production Evolution Upgrade**: the **Higher-Order Quant Factor & Operator Library Expansion**.

To eliminate reliance on simple moving averages and static breakout rules, Phase 2 equips the Blue Team Quant and MCTS Mutation Engine with an extensible library of domain-tailored quantitative operators. These operators cover orderbook microstructure, volume profiles, volatility channels, and momentum z-scores, allowing LLM-driven MCTS mutation operators to synthesize sophisticated multi-factor strategies.

## 2. Operator Specifications

### 2.1 Microstructure & Orderbook Operators
* **`compute_orderbook_imbalance(bids, asks, depth=5)`**:
  Calculates the normalized bid-ask volume imbalance ratio:
  $$I_{ob} = \frac{\sum_{i=1}^d V_{bid,i} - \sum_{i=1}^d V_{ask,i}}{\sum_{i=1}^d V_{bid,i} + \sum_{i=1}^d V_{ask,i}} \in [-1, 1]$$
  High positive values indicate strong near-term buying pressure.

### 2.2 Volume & VWAP Operators
* **`compute_vwap_zscore(candles, window=20)`**:
  Calculates Volume-Weighted Average Price (VWAP) and the z-score of current price distance:
  $$Z_{vwap} = \frac{P_{close} - VWAP}{\sigma_{vwap}}$$
  Used to detect mean-reversion and momentum extension states.

### 2.3 Volatility & Channel Operators
* **`compute_atr_volatility_channel(candles, period=14, multiplier=2.0)`**:
  Computes Average True Range (ATR) adaptive channels:
  $$Upper = MA_{close} + (K \times ATR), \quad Lower = MA_{close} - (K \times ATR)$$
  Replaces fixed percentage stop losses with volatility-adaptive dynamic stops.

The `BlueTeamQuant` prompt templates and `ARCGeneticMutator` AST transformation rules are updated to recognize and utilize these operators. Candidate strategy code generated by Blue Team will automatically select from this operator library based on the market regime and instrument profile.
