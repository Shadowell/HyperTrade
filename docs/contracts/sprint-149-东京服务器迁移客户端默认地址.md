# 迭代名称

Sprint 149：东京服务器迁移客户端默认地址

## 目标

旧机停用后，HyperTrade CLI 与桌面端默认连接东京服务器 2，并保护用户设置的其他 API 地址。

## 范围内

- 更新 CLI 和桌面端默认 API 地址为 `http://64.83.43.61:3333`。
- 桌面端读取到历史旧默认地址时使用新默认值；其他已保存地址保持原样。
- 测试空输入、旧默认地址和自定义地址。

## 范围外

- 不更改认证、交易权限、Paper 数据、容器端口或服务器 DNS。
- 不在新机完成健康验收前触发生产部署。

## 完成标准

- 定向测试与 `./scripts/check.sh` 通过。
- 目标机 API 真实健康检查通过后，代码合入 `main`，GitHub 部署与客户端连接可核对。

## 取代关系

旧机 IP 仅保留为桌面端历史设置识别值，不再作为新连接的默认目标。
