# 东京服务器迁移后的 HyperTrade 默认连接地址

**日期**：2026-09-24
**分支**：`codex/tokyo2-api-host`
**状态**：已澄清

## 用户场景与验收

东京旧机停用后，新的 CLI 登录及桌面端首次启动应连接新机 `64.83.43.61:3333`。桌面端若曾保存旧机的默认地址，也应自动使用新地址；用户主动设置的其他 API 地址必须原样保留。

## 功能需求

- **FR-001**：CLI 的空输入默认 URL 指向新机。
- **FR-002**：桌面端无保存地址时默认指向新机。
- **FR-003**：桌面端仅将保存的旧默认 URL 解析为新默认 URL，不覆盖自定义 URL。
- **FR-004**：测试覆盖旧默认、自定义和无保存地址三种情况。

## 成功标准

- **SC-001**：CLI、桌面端定向测试和项目检查通过。
- **SC-002**：切换后通过新机地址的真实 API 健康检查；部署回执与服务状态另行核对。

## 边界

不改交易权限、订单、Paper 数据、服务认证或 Nginx 端口。旧地址只用于识别历史本地设置，不再作为活动默认目标。
